reales encontrados en código ya escrito, no features nuevas. Cada entrada
referencia el sprint donde se detectó y dónde queda el detalle completo.

Convención de numeración: prefijo de letra por sprint donde se detectó
(A = Sprint 1, B = Sprint 2, C = Sprint 3), número secuencial dentro del
sprint. Si una entrada ya está descrita en detalle en `ARCHITECTURE.md`,
esta tabla solo resume y enlaza — no duplica el razonamiento completo.

## Cómo agregar una entrada

Al cerrar un hallazgo (sea de auditoría formal o de troubleshooting en vivo
durante una sesión de trabajo), agregar una fila acá con: sprint, qué se
encontró, severidad percibida, estado (abierto/cerrado) y dónde vive el
detalle completo del razonamiento (normalmente `ARCHITECTURE.md` o un
documento de sesión). No repetir acá el detalle completo — este archivo es
un índice rápido, no el lugar para la explicación extensa.
